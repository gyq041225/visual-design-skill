## 字体

中文规范为苹方；原文中文标题使用 Medium，扩展标题表又标注 bold。按目标效果图和具体组件决定 500 或 600，不把所有标题统一加粗。

| 用途 | 字号/行高 px |
|---|---|
| B1/B2/B3 运营标题 | 56/64、46/52、36/48 |
| H1/H2/H2-1/H3 | 24/34、20/30、18/28、16/26 |
| H4（标注文案） | 14/22 |
| T1-1/T1/T2 | 18/28、16/26、14/22 |
| T3/T4/T5 | 12/20、11/13、10/12 |

14px正文段间距至少21px；主副层级字号差2–4px。辅助信息在对应主信息下方或右侧，间距≤8px；与其他模块间距≥16px。
CSS 字体回退可用 `"PingFang SC","Microsoft YaHei",sans-serif`；这是实现建议，Windows 下应核对字体替换后的换行。

## 间距、布局与形状

- 通用间距档位 8/16/24/32px，来自 `0:557`。引用 Arco 的原始间距 4/8/16/24 并非本方案默认档位。
- 业务中后台可用24列；多终端布局说明为小屏4、平板8、桌面12列。按项目类型选择，不强制所有页面采用同一列数。
- 顶部导航：常规64px、二级48px；展示页80px、二级56px。固定版心示例1200px，应用型布局可通栏和折叠侧栏。
- 圆角常用4/8/12/16/28px及全圆角；其他列出0/20/32/48px。全圆角胶囊用足够大的半径，只有圆形容器使用50%。
- 边框宽0/1/2/3px。
- 状态层：hover 8%、focus 12%、pressed 12%、dragged 16%；叠加在底色上，不直接降低整个组件透明度。
- 禁用按钮：文字主文字色38%，凸起/填充/色调底色主文字色12%。
- 海拔0–5分别为基础、轻微悬浮、小交互、卡片列表、临时浮层、重要模态/FAB；数值阴影尚未提取，不编造为官方值。

## 已知差异与适用边界

1. `0:2805` H4 文案14/22，文字图层实际16/26；默认以标注文案作为待确认值，不声称已解决。
2. `color-bg-white` 文案旁数值写成 #192024，与“白色背景”冲突；CSS 暂采用 #FFFFFF，并标记为语义推定。
3. 表面色总结含另一组偏紫背景，且存在蓝色备份、绿色、紫色方案；不可混合主题。
4. 主色前景说明存在容器前景与实心按钮前景混写；按钮必须按具体目标校验。
5. 列表说明同时出现56、48及54高度；按密度和具体目标选择。
6. 部分抽屉、空状态、列表说明有明显复制文案，不视为该组件的交互规范。
7. 部分组件规则仅以位图表示；没有提取到不代表没有要求。需要时重新读取对应节点。
